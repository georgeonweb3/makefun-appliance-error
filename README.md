One honest appliance error message, judged head to head in pairs. Free to enter.

The entry (135 characters):

> ERROR: I heated your soup for 3 minutes. The bowl is lava. The soup is ice. I have done exactly what you asked, and nothing you wanted.

The microwave did heat the soup, but physics betrayed it — bowl lava, soup ice — and it closes on the machine's flat, literal-minded verdict: it did exactly what was asked, and nothing that was wanted. No missing sock, no unbalanced load, no fridge light that works while the cooling does not.

## Run it

```sh
python3 main.py
```

This writes the error message to `/output/entry.txt` (UTF-8, no trailing newline).
